# Upstream copies of generated resources

These files are byte-for-byte copies of resources from the upstream Spring Boot `1.5.22.RELEASE` jars published in Maven Central. They are generated by annotation processors during the build and their bytes depend on the build (entry order and, for the properties file, the build date). In the `luxlabs-tomcat9` profile, `luxlabs/tools/UpstreamResources.java` runs in the `process-classes` phase of `spring-boot` and `spring-boot-autoconfigure`: it checks that each generated file has the same content as its upstream copy and then replaces it with the copy, so that the fork jars carry the upstream bytes. A generated file that is missing or has different content fails the build.

| Equivalence | Rule |
| --- | --- |
| `Log4j2Plugins.dat` | Same plugin entries (category, key, class, name, printable, defer), in any order |
| `.json` | Same objects, members and array elements in any order |
| `.properties` | Same keys and values |
